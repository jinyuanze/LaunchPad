# LaunchPad for macOS

一个复刻并增强 macOS 原生启动台（Launchpad）体验的现代化应用启动管理工具。

## ✨ 特性一览

- 🚀 **双浏览模式**：支持经典翻页（Paged Matrix）与纵向滚动（Smooth Vertical Scroll）模式无缝切换。
- 🖥️ **双视窗形态**：支持沉浸式全屏（Full Screen）与悬浮轻量窗口（Floating Window）模式。
- 🔍 **智能搜索与键盘导航**：
  - 支持应用名称、拼音缩写、首字母及包含度智能加权排序。
  - 原版高亮胶囊选中指示（Title Pill Highlight）。
  - 支持键盘方向键（`↑` `↓` `←` `→`）及 `Tab` / `Shift+Tab` 顺畅选定，敲击回车直接秒开应用。
- 📁 **文件夹与批量整理**：
  - 支持多选（按住 `Cmd` 多选）批量合并新建文件夹、批量移动。
  - 支持文件夹层级动画展开与拖拽进出。
- 🎨 **原生壁纸磨砂半透明背景**：
  - 自动捕获当前屏幕桌面壁纸并进行原版同款实时高斯模糊，与系统自然融为一体。
- 👆 **原生触控手势与快捷键**：
  - 支持触控板四指捏合唤出。
  - 支持硬件 F4 启动台键与自定义 Carbon 全局快捷键唤出。
- 🗑️ **长按晃动卸载模式**：
  - 按住 Option 键进入晃动卸载模式，支持深度扫描并清理应用残留。

## 🛠️ 构建与运行

### 系统要求
- macOS 14.0 (Sonoma) 或更高版本
- Xcode 15+ 或 Command Line Tools (Swift 5.10+)

### 快速编译打包
运行仓库自带的自动化打包脚本：

```bash
./scripts/build_app.sh
```

编译完成后产物将生成在 `build/LaunchPad.app`，并完成本地 ad-hoc 签名，直接双击即可运行。
